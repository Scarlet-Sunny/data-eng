  1) 히어독으로 compose 파일을 만들고 minio, mcfmf Up으로 띄운다.
  2) 웹 콘솔(9001, SILO)에 minioadmin으로 로그인해 둘러 본다.
  3) mc 안에서 minio:9000은 되고 localhost :9000은 안됨을 본다.

##실행방법
  - docker compose config --services
  - docker compose up -d
  - docker compose ps # 상태확인

##로그확인 : 
  - docker compose logs 서비스명으로 이유 확인
    (ex) docker compose logs -f minio)
